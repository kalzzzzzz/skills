# 中药控股红色科技风 - 设计规范

## I. 模板概述

| 项目     | 值                                             |
| -------- | ---------------------------------------------- |
| 模板名称 | 中药控股红色科技风                             |
| 模板 ID  | zhongyao_red                                   |
| 分类     | brand（品牌模板）                              |
| 适用场景 | 企业汇报、项目汇报、部门工作汇报               |
| 设计基调 | 现代、专业，红色为主调，融合中式传统元素       |
| 主题模式 | 浅色主题（白色背景 + 红色点缀 + 传统纹样装饰） |

## II. 画布规范

| 项目    | 值             |
| ------- | -------------- |
| 比例    | 16:9           |
| 尺寸    | 1280 × 720 px  |
| viewBox | `0 0 1280 720` |

## V. 页面结构

### 整页底图说明

| 底图文件         | 用途   | 包含元素                                             |
| ---------------- | ------ | ---------------------------------------------------- |
| `bg_cover.png`   | 封面页 | 红色纹样背景、国药集团Logo、公司完整Logo             |
| `bg_toc.png`     | 目录页 | 左侧红色区域、印章、目录标题、中国中药Logo、底部纹样 |
| `bg_chapter.png` | 章节页 | 顶部/底部纹样条、中国中药Logo、左侧红色竖条          |

| `bg_ending.png`  | 结尾页 | 国药集团Logo、中央公司Logo、底部纹样                 |

### 安全内容区域

由于底图已包含所有装饰元素，内容区域建议：

- **封面页**：标题居中，注意避开底部公司Logo区域（y > 620px 为安全区）
- **目录页**：内容在右侧白色区域（x > 620px）
- **章节页**：内容在右侧白色区域（x > 180px）
- **内容页**：内容在 y > 120px 且 y < 660px 的安全区
- **尾页**：无需额外内容

## VIII. 占位符规范

### 封面

| 占位符         | 用途            | 位置建议              |
| -------------- | --------------- | --------------------- |
| `{{TITLE}}`    | 主标题          | 页面中央偏上（y≈300） |
| `{{SUBTITLE}}` | 副标题/所属部门 | 主标题下方（y≈380）   |
| `{{DATE}}`     | 时间            | 页面中下部（y≈550）   |

### 目录页

| 占位符           | 用途          | 位置建议                     |
| ---------------- | ------------- | ---------------------------- |
| `{{TOC_ITEM_1}}` | 第一部分：xxx | 右侧白色区域（x≈620, y≈220） |
| `{{TOC_ITEM_2}}` | 第二部分：xxx | 右侧白色区域（x≈620, y≈270） |
| `{{TOC_ITEM_3}}` | 第三部分：xxx | 右侧白色区域（x≈620, y≈320） |
| `{{TOC_ITEM_4}}` | 第四部分：xxx | 右侧白色区域（x≈620, y≈370） |

### 章节页

| 占位符              | 用途     | 位置建议                 |
| ------------------- | -------- | ------------------------ |
| `{{CHAPTER_NUM}}`   | 第x部分  | 右侧区域（x≈180, y≈280） |
| `{{CHAPTER_TITLE}}` | 章节标题 | 编号下方（x≈180, y≈340） |

### 内容页

| 占位符             | 用途     | 位置建议               |

## IX. SVG 技术约束

- viewBox 统一为 `0 0 1280 720`
- 禁用 `<foreignObject>`
- 文本使用标准 `<text>` 元素
- 颜色使用 HEX 值，确保一致性
- 底图使用整页PNG，通过 `<image>` 标签引用
- 占位符使用 `{{PLACEHOLDER}}` 格式
- 图片元素使用 `<image>` 标签，设置 `preserveAspectRatio="none"` 属性
